# 誰が買うのか ―― 「覚醒」を商品から外し、金額で痛みを持つ買い手に売り直す

作成日: 2026-09-06 JST
位置づけ: [実績ゼロ立ち上げ戦略](./後藤美佳_実績ゼロ立ち上げ戦略.md)への根本的な修正。「宗教みたいで売れない」という指摘を正として、買い手・商品・言葉を再定義する。

---

## 1. 指摘の何が正しいか(直視する)

| ふわふわの要素 | なぜ売れないか |
|---|---|
| 「覚醒」「潜在意識の顕在化」という語彙 | 対外的にはスピリチュアル・自己啓発系とパターン一致する。海外(英語圏)ではなおさら "awakening" は新興宗教の棚に置かれる |
| コーチ・支援職個人に認定を売る構図 | 「情報を売る人に情報を売る」循環市場。SBCやプラチナ顧問ファネルと同じ棚であり、データ無しでは信念で買ってもらうしかない=宗教と同じ購買構造 |
| 「創設メンバーの称号」「証拠を一緒に書く」 | 買い手の事業の数字を1円も動かさない。共感した人しか買わず、共感で買う人は続かない |

**共通の根本原因: 買い手の痛みが金額で表現されていなかった。** 痛みが金額でない限り、支払いの根拠は信念になる。信念で売るものは宗教に見える。当然の帰結だった。

## 2. 売れる条件

**「その問題で、すでに毎月お金を失っている買い手」にだけ売る。**
覚醒モデルが扱う現象 ――「何をしても動かない人」(学習性無力感・外部基準依存)―― で、現実に金を失っている事業者は存在する。そこが市場になる。

## 3. 具体的な買い手(国内・第一候補)

### 就労移行支援・就労継続支援・自立訓練の事業所

- 全国に事業所は数千〜1万超。収益は訓練等給付費で、**基本は日割り ―― 利用者がその日通所しなければ、その日の売上はゼロ**。
- つまり「動かない利用者」「来なくなる利用者」は、この業界では感情の問題ではなく**毎月の減収**。利用者1名の通所が止まれば月あたり概算10万円規模の給付が消える(単価は事業類型・地域で異なる。契約前に対象事業所の実単価で試算する)。さらに就職率・定着率は報酬加算に直結する。
- 現場の支援員は「意欲がない」「甘え」と本人の資質に帰属しがちで、打ち手を持っていない ―― まさに[外部基準依存の理解](./外部基準依存の理解.md)が書かれた状況そのもの。

**この買い手にとっての商品:**

| 要素 | 中身 | 買い手にとっての意味 |
|---|---|---|
| 支援員研修 | 「動かない利用者」のアセスメント枠組み(7段階は内部プロトコルとして使う)+ステージ別の介入手順。4層理論は研修教材の科学的根拠パート | 支援員が打ち手を持つ。離職しやすい支援員の定着にも効く |
| 進捗管理ツール | REVERA01(仮名運用・記録・役割権限はこの用途にほぼそのまま合う) | ケース記録と支援の標準化。実地指導対応の記録にもなる |
| 効果測定 | 利用率(通所日数)・6ヶ月継続率・就労移行数の前後比較 | **金になる指標で測る。** ステージ遷移は内部指標に格下げする |

### 同じ構造の隣接市場(第二候補群)
- 就労定着支援(離職=報酬減)
- 自治体のひきこもり支援・生活困窮者自立支援の委託事業者(成果報告義務)
- 通信制高校・サポート校(中退=学費収入減)
- EAP・休職復職支援(復職率が契約更新に直結)

### 海外(順番として後)
welfare-to-work の成果連動契約(英・豪・米の workforce development)、supported employment、難民就労統合 ―― すべて成果報酬型で「エンゲージしない対象者」が収益問題になっている市場。**国内で数字を作ってから**同じ商品(職員研修+プロトコル+計測)を持ち込む。海外展開設計書のファネルはその時点で再起動する。

## 4. 商品第一号: 90日利用率改善パイロット

| 項目 | 設計 |
|---|---|
| 対象 | 1事業所(まず1つ。福井プロポの代替もこれ) |
| 期間 | 90日 |
| 価格 | 15〜30万円(研修2回+プロトコル導入+アプリ+月次レビュー) |
| 測定 | 開始前3ヶ月の利用率をベースライン→終了時に前後比較 |
| リスク反転 | 利用率が改善しなければ次の90日を無償継続 |
| 副産物 | **これが最初のデータになる。** Founding Cohort構想の役割はこのB2Bパイロットが引き継ぐ |

改善が数字で出れば、営業資料は1枚で足りる:「利用率◯%→◯%(n=◯、90日)。御所の単価なら月◯円の給付が守られます」。宗教の語彙は一語も要らない。

## 5. 販売方法(B2B・現実版)

- **買い手の中の人**: 事業所の経営者・施設長(現場支援員ではない。稟議の起点は減収データ)。
- **動線**: 紹介・業界団体・事業所向け無料勉強会(60分)・直接訪問。広告は使わない。
- **営業の中身**: 勉強会や商談で、その事業所の「一番動かない利用者」(仮名)を聞き、その場でアセスメント枠組みに載せて「なぜ今の声かけが逆効果か・明日から何を変えるか」まで言い切る。**ライブ診断のデモは対個人向け構想から唯一持ち越す営業ツール** ―― ただし刺す先は施設長の「減収と支援員の疲弊」。
- **後藤個人の実績だけで戦える理由**: B2Bの小口パイロットで意思決定者が見るのは(a)現場をわかっている言葉か、(b)リスクが小さいか、の2点。(a)は診断デモで、(b)は15〜30万+成果保証で満たす。個人実績の薄さは価格とリスク反転で埋める。

## 6. 何を捨て、何を残すか

| 捨てる(対外) | 残す(内部・転用) |
|---|---|
| 「覚醒」「潜在意識」という対外語彙 → 「定着支援」「行動活性化」「中断予防」へ | 七段階モデル=支援員研修の内部プロトコル(名称・順序は非交渉のまま、外に出す言葉だけ変える) |
| コーチ向け認定を最初の商品にすること | 認定は将来、導入事業所が増えた後の研修講師育成として復活しうる |
| 創設メンバー・称号の販売 | REVERA01アプリ(この用途に設計がそのまま合う) |
| データ無しでの海外先行 | 4層理論=研修の科学的根拠パート+英語ホワイトペーパー(順番が後になるだけ) |

## 7. 90日の動き(改訂)

1. Day 1〜14: 商品資料A4×2枚(事業所向け・金額の言葉で)/ 研修カリキュラム骨子 / 対象事業所リスト20件(地元・紹介経路から)
2. Day 15〜45: 勉強会1回開催+個別訪問 → パイロット1件契約
3. Day 46〜90: パイロット実施・月次レビュー・データ取得開始
4. Day 90+: 前後比較レポート→2件目・3件目へ横展開(価格を上げる)。行政・海外はデータが出てから。
