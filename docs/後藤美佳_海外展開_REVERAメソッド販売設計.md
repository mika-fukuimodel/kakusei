## 0. 結論(先に全体像)

**売るのは「コーチング」ではなく「メソッドの実装権」。**

- 商品の柱は **REVERAメソッド国際認定(Practitioner Certification)** と **組織向けライセンス+顧問(Organizational License & Advisory)**。個人向けセッションは柱にしない。
- 買い手は海外の **支援職・コーチ・ソーシャルワーカー・HR/ウェルビーイング担当・NGO/社会的企業**。エンドユーザー(行き詰まった本人)は買い手の先にいる(B2B2C)。
- 説得構造は「後藤美佳=モデルの設計者であり、それを**動くプラットフォームとデータで運用している唯一の人物**」。人柄営業ではなくIPと実装で信じさせる。
- ファネルはプラチナ顧問ファネル型(英語VSL→審査→Zoom面談→高単価)を常設し、ACTION型チャレンジは四半期に1回のスポット増幅として使う。

## 1. アセット棚卸し ―― 「後藤美佳だから」の中身

| アセット | 海外市場での意味 |
|---|---|
| 七段階覚醒モデル(封鎖状態→信頼の構築→潜在意識の顕在化→主体の回復→小さな挑戦→障害の突破→場の創造と還元) | 体系化済みの独自フレームワーク。海外のコーチング市場は「動機づけ」偏重で、**学習性無力感・外部基準依存の人には効かない**という穴がある。その穴を正面から扱う7段階は明確な新規性 |
| 4層の科学的説明体系(脳神経科学/心理学/内分泌/発達環境) | "モチベーションの問題ではなく適応の結果" という再定義は、trauma-informed(トラウマインフォームド)の国際的潮流と完全に噛み合う。学術語彙で語れることが海外での信用の通貨になる |
| REVERA01アプリ(ステージ進行の記録、参加者/支援者/ディレクターの3役割、仮名コード運用、RLSによる最小権限) | ①メソッドが**計測可能**である証拠 ②supporter/director構造は**そのまま国際認定の階級**に転用できる ③仮名設計は「プライバシー・バイ・デザイン」としてGDPR圏で強い訴求になる |
| ステージ7「場の創造と還元」の思想 | 修了者が次の支援者になる=**認定ビジネスの拡張構造がモデル自体に内蔵**されている。「教えを広める人を育てる」ことがメソッドの完成形なので、認定販売が思想的に自然 |
| 日本発であること | ikigai・kaizen同様、「日本発の構造化された人間回復メソッド」は海外でカテゴリとして立つ。REVERAを固有名詞のまま輸出する |

**新規性の一文(英語ポジショニング):**
> REVERA — the Japanese 7-stage framework for restoring human agency. Stage-tracked, privacy-first, built for the people motivation coaching leaves behind.

(直訳: モチベーション型コーチングが取りこぼす人々のための、日本発・7段階のエージェンシー(主体性)回復フレームワーク。ステージ計測型・プライバシー最優先。)

## 3. 説得構造 ―― 実績ゼロの海外市場でどう信じさせるか

ACTION分解で確認した通り、**金額実績より非金銭・第三者証拠が強い**。海外初期は日本の売上を語っても通じないため、以下の順で証拠を積む。

1. **モデルの深さを見せ切る**: 4層の科学的説明を英語ホワイトペーパー化(「Why motivation coaching fails: the neuroscience of external-criteria dependence」)。VSLの前半で理論を惜しみなく公開する(ACTIONの「概念は全部見せる、実装は商品で」方式)。
2. **プラットフォームをデモする**: ステージ進行画面・仮名設計を動画で見せる。「フレームワークがソフトウェアとして動いている」だけで、PDF売りのコーチと別カテゴリになる。
3. **ステージ進行カードを事例フォーマットにする**: ACTIONのBEFORE/AFTERカードを転用し、「U001: Stage 1→4 in 16 weeks」のように**仮名+ステージ遷移+支援者の観察引用**で構成。仮名なのはプライバシー設計ゆえ、と明記すれば弱点が思想の証明に変わる。
4. **国際パイロット10名を先に作る**: 第0期として海外の支援職10名を無料〜実費で認定し、各自の現場での適用事例カードを獲得する(60日)。以後のLP・VSLの証拠はここから供給。
5. **制度側の権威を取りに行く**: コーチング継続教育(ICF CCE等)のクレジット認定、大学・NGOとの共同パイロット、国際カンファレンス登壇。SBCが経産省・JETRO採択で信用を作ったのと同じ動き方を、国際機関・業界団体で行う。

## 4. ファネル設計(英語)

### 4-1. 常設: エバーグリーン顧問ファネル型

```
広告(Meta + LinkedIn ※B2B職種名指し)
  ▼
LP(入力はメール1項目のみ / ACTION方式)
  ▼
英語VSL 45分
  ①なぜ動機づけコーチングは効かない人に効かないのか(4層の科学)
  ②7段階モデルの全体像(理論は全公開)
  ③プラットフォームのデモ+パイロット事例カード
  ④オファー: 認定コホート(定員制・審査制)のDiscovery Call
  ▼
審査フォーム(Step2で選択式5問: 職種/支援対象/経験年数/導入予算/開始時期)
  ├─ 適格 → 事前課題+リマインド → Discovery Call → 認定 or 組織ライセンス
  └─ 準適格・不適格 → REVERA Circle(月額) or ミニコースを自動オファー
```

- 打ち消し表示をスクリーニングに兼用(ACTION方式):
  「REVERA is a 12-week practice, not a quick fix. If you need results this month, this program is not for you.」
- 面談前ナーチャリング: 事例動画2本+ホワイトペーパーを自動配信。show率と成約率を守る(実務設計書§2-4と同一)。

### 4-2. スポット: 四半期チャレンジ(ACTION型)

- 「5-Day Agency Restoration Challenge」: 支援職向けに、自分のクライアント1名のステージ診断→介入設計までを5日で作らせる。成果物は「ステージ診断シート」と「介入プラン」(ACTIONの企画書+台本方式)。
- 開催は年3〜4回のみ。エバーグリーンで教育しきれない層をライブの熱量で刈り取る。常設はしない(後藤の稼働を守る)。
- 配信はライブ+英語字幕。時差はUS/EUの重なる日本時間22〜24時 or 早朝に固定し、録画補講を標準化。

### 4-3. 出稿戦略

| 媒体 | 役割 | 備考 |
|---|---|---|
| Meta(FB/IG) | 主力テスト。コーチ・支援職の興味関心+類似 | クリエイティブ1行目で「For coaches, social workers & HR leads」と職種名指し(ToC排除) |
| LinkedIn | 組織ライセンス向け。職種・業界ターゲティングが正確 | CPL高いが単価$20k商品なら成立。ホワイトペーパーDL型 |
| YouTube | VSL相性・第2フェーズ | 英語圏の「learned helplessness」「trauma-informed coaching」関連へ |

- テスト→検証→スケールのルール、週次KPI(CPL/申込率/show率/成約率/ROAS)は実務設計書§3-3をそのまま適用。英語圏はCPLが日本より高い前提で、認定$5,000+の単価がそれを吸収する構造にする。

## 5. 働き方・体制(後藤の実働 週10時間以内)

| 役割 | 担当 |
|---|---|
| 講義・Discovery Call・組織顧問・最終判断 | 後藤美佳(週6〜8h) |
| 英語化(教材翻訳・ネイティブ監修)/通訳・字幕 | 外注(AI翻訳+ネイティブチェックの2段構え。登壇は逐次通訳or吹替) |
| 広告運用・LP・計測 | 外注(英語圏運用経験のある代行) |
| 事務局(申込管理・リマインド・コミュニティ一次対応) | オンライン秘書(英語対応) |
| 添削・受講生サポート | 認定Directorへ段階委譲(ステージ7の思想通り、修了者が担う) |

ツールは最小構成: LP/決済(Stripe・USD建て)・配信(メール。海外はLINEでなくEmail+コミュニティはCircle/Slack等1つ)・予約(Calendly系でタイムゾーン自動変換)・面談(Zoom)・管理(スプレッドシート1枚)。

## 6. リスクと法務(海外特有)

- **医療・心理療法の非標榜**: learned helplessness・トラウマ等に触れるため、「教育プログラムであり治療・診断ではない」旨の免責を全教材・LP・契約書に明記。危機対応(自傷リスク等)は各国のホットラインへ誘導する運用手順を認定カリキュラムに含める。
- **GDPR/各国プライバシー法**: REVERA01の仮名設計は追い風だが、EU居住者を扱うならGDPR対応(処理根拠・DPA・データ所在)を整理。組織ライセンス契約にデータ処理条項を入れる。
- **商標**: 「REVERA」の商標を主要展開国(US/EU/UK)でクリアランス調査→出願。類似名の化粧品等が存在しうるため区分(41類 教育/42類 SaaS/44類は避ける)を専門家と確認。
- **表示規制**: 成果表示は非金銭(ステージ遷移・事例数)中心+個人差の打ち消し。米FTCの推薦広告規制(体験談には典型的成果の開示)に準拠。
- **決済・税務**: Stripe(USD/EUR)、越境の消費税(EU VAT MOSS等)は決済代行のMerchant of Record(Paddle等)利用も検討。
- **属人性**: 講義・添削の英語コンテンツ化とDirector委譲を初年度から進め、後藤が止まっても認定が回る状態をつくる。

## 7. ロードマップ(120日)

### Phase 0: IPパッケージング(Day 1〜30)
- 7段階モデル・4層理論の英語ホワイトペーパー化(翻訳+ネイティブ監修)
- 英語ネーミング・トーン決定(REVERA Method / Practitioner / Director)、商標クリアランス調査
- 事例カードのテンプレ設計(仮名+ステージ遷移+観察引用)、免責文言の整備
- REVERA01アプリのUI英語化(i18n)最小対応

### Phase 1: 第0期パイロット(Day 31〜75)
- 海外の支援職10名を招待制で無料認定(既存人脈・LinkedIn直接声かけ・日本在住外国人支援職)
- 週1講義×6週の短縮版。各自の現場適用→事例カード10枚を獲得
- 並行: 認定カリキュラム正式版(12週)と価格・定員の確定、Circleの器を準備

### Phase 2: ファネル構築(Day 60〜90)
- 英語VSL台本→撮影(字幕/吹替)→編集、LP(メール1項目)+審査フォーム+ナーチャリング設定
- Stripe/Paddle決済、Calendly、KPIダッシュボード整備
- 特商法相当の表記(Terms/Privacy/Disclaimer)英語版公開

### Phase 3: テスト出稿→第1期販売(Day 91〜120)
- Meta少額テスト(日$50〜100)→CPL・面談予約単価を検証、勝ちクリエイティブへ集約
- Discovery Call開始、第1期認定コホート(定員10)を成約目標5〜8名でローンチ
- 初回「5-Day Challenge」をリストが500名を超えた時点で企画(超えるまでやらない)

**Phase 3の合格ライン**: 面談→成約率30%以上・コホート損益分岐(広告費+外注費)超え。未達ならスケールせずボトルネック1点改善(実務設計書§6の改善ループを適用)。

## 8. まとめ ―― 何が「後藤美佳だから」なのか

1. モデルの**設計者本人**であること(輸入コーチングの再販ではない)
2. モデルが**ソフトウェアとして稼働し、ステージ遷移として計測できる**こと
3. 仮名運用=**尊厳とプライバシーを設計思想に持つ**こと(GDPR圏でそのまま強み)
4. ステージ7「場の創造と還元」により、**認定で広げることがメソッドの思想的帰結**であること

この4点が揃っているプレイヤーは海外のコーチング/支援市場にほぼ存在しない。だから売り物は時間ではなくメソッドの実装権であり、ファネルはそれを高単価・少数・審査制で売るプラチナ顧問ファネル型が最適、という結論になる。
