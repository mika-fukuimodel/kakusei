デザイン指定: 白背景・数字は大きく・装飾は最小限。福祉業界の資料はシンプルなほど信頼される。「覚醒」「潜在意識」等の語彙は使用禁止(内部プロトコル名も資料には出さない)。

## 1枚目(表): 問題提起とオファー

---

### 通所が止まった利用者、何名いますか。

**利用者1名の通所が止まると、事業所の減収は 月あたり 約10万円**(※)。
加えて、就職率・定着率の低下は報酬加算に直結します。

※ 日割り給付単価×平均通所日数による概算。本パイロットの冒頭で、貴所の実単価・実データで正確に試算します。

---

**「声かけしても来ない」「意欲が見えない」「支援員が疲弊していく」**

その利用者は、意欲がないのではなく、
**「自分で決めて動く」機能が長年の環境で働かなくなっている状態**です。

この状態には、励まし・目標設定・通常の声かけは効きません。
**効かないどころか、逆効果になる声かけのパターンが特定されています。**

私たちは、この「動かない状態」を段階で見立て、
段階ごとに支援員の関わり方を変える実務プロトコルを提供しています。

---

### 90日利用率改善パイロット

| | |
|---|---|
| 内容 | 支援員研修2回 + ケース見立てプロトコル導入 + 記録ツール + 月次レビュー3回 |
| 測定 | 開始前3ヶ月の利用率(通所実績)をベースラインに、90日後と前後比較 |
| 費用 | ◯◯万円(税別)※15〜30万円の範囲で確定後に記載 |
| **保証** | **利用率が改善しなければ、次の90日間の支援を無償で継続します** |

**まずは60分、無料の所内勉強会から。**
貴所の「一番手応えのないケース」を1件、その場で一緒に見立てます。

連絡先: (後藤美佳/所属/メール/電話) ← 要記入

## 2枚目(裏): 中身と根拠

---

### パイロットの90日間

| 週 | 実施内容 |
|---|---|
| 第1週 | 現状分析: 貴所の利用実績データで減収額を試算。対象ケースの選定(3〜5名) |
| 第2週 | 支援員研修①(2時間): 「動かない状態」の科学的な仕組みと、段階の見立て方 |
| 第3〜6週 | プロトコル運用開始: 対象ケースを段階で見立て、関わり方を変更。記録ツールで経過を記録 |
| 第6週 | 支援員研修②(2時間): ケース検討会形式。実際の経過を教材に見立てを修正 |
| 第7〜12週 | 運用継続 + 月次レビュー(施設長・サビ管と30分×3回) |
| 第13週 | 前後比較レポート提出: 利用率・対象ケースの通所日数・支援員の所感 |

### 支援員が持ち帰るもの

- 「意欲がない」で止まらない、**7つの段階でのケースの見立て方**
- 段階ごとの「効く関わり/逆効果になる関わり」の一覧
- 見立てと経過を残す記録ツール(仮名運用・個人情報の追加取得なし)

### なぜ効くと考えるか(根拠の性質を正直に)

- プロトコルは、脳科学・心理学(学習性無力感・自己効力感)・発達環境の研究知見に基づいて設計されています。
- **本パイロットは効果実証の第一号です。** 効果を証明済みとは申しません。だからこそ、改善しなければ次の90日を無償とする保証を付けています。
- 測定は貴所の給付実績と通所記録という客観データのみで行います。

### よくある質問

- **Q. 支援員の負担は増えませんか** ― 研修2回(各2時間)以外は、日常業務内の関わり方と記録の仕方を変えるだけです。新しい業務は追加しません。
- **Q. 利用者の個人情報は** ― 記録ツールは仮名(コード)運用で、氏名・住所等の入力を必要としません。
- **Q. 対象はどんな利用者ですか** ― 通所が不安定/声かけへの反応が乏しい/「決められない」傾向のある方。急性期の医療的対応が必要な方は対象外です(医療の代替ではありません)。

## 使い方メモ(資料には印刷しない)

1. 空欄(価格・連絡先・プロフィール・実単価)を埋めてから使う。**実単価の試算は必ず相手のデータでやる**(こちらの概算数字で押さない)。
2. 手渡しの順番: 勉強会→この資料、または訪問時にこの資料→勉強会の提案。資料を先にばら撒かない(1枚目の問いは対面で言うのが一番効く)。
3. 1枚目の「約10万円」は概算である旨の※を必ず残す。誇張と受け取られたら終わり。
