# 競合ファネル分解: ACTION 4Daysチャレンジ(SBC / 株式会社やまやま)

作成日: 2026-08-30 JST
対象: action4-lp.vercel.app/lp-ad002/(Facebook広告流入用LP、全60スクリーン分のキャプチャPDFより)
関連: [プラチナ顧問ファネル 実務設計書](./プラチナ顧問ファネル_実務設計書.md)

## 1. これは何のファネルか

社会起業スクール「SBC」(主宰: 猪原有紀子氏系列、運営: 株式会社やまやま)の**フロントエンド集客イベント**。

```
Meta広告(lp-ad002 = LPを広告別に複数バリエーション運用、utmでフル計測)
   ▼
登録LP(入力はメールアドレス1項目のみ)
   ▼
LINEオープンチャット(参加者専用・案内はすべてここ)
   ▼
無料4Daysチャレンジ(9/4・8・11・15 の21時、ライブ・オンライン)
   各日で「事業企画書」と「プレゼン台本」を実際に作らせる
   ▼
(LP外)最終日以降にバックエンド = 有料スクールSBCへのオファー(推定)
```

型としては**チャレンジローンチ(コホート型ライブローンチ)**。エバーグリーンVSL型ではない。

## 2. LP構成(60スクリーンの流れ)

1. ヒーロー: ターゲット名指し「社会にいいことをビジネスに変える方法が分からない方へ」+ 権威(メディア掲載300件超・上場企業/大学で講演)+ 日程・完全無料・オンライン
2. オプトインフォーム(メール1項目+緑CTA「今すぐ無料で参加する」)+ 特典(社会起業入門ガイドブックPDF)
3. 悩み3つ(マネタイズできない/SNS起業ではなく社会性/ボランティアから抜け出せない)
4. 特典の中身見せ
5. **打ち消し兼スクリーニング文**「※社会起業は少なくとも3年はかかるため、短期的な成果を求める方には不向きです」
6. 特徴3つ(76%がゼロから/学びで終わらず企画書+台本が残る/受講生の7割が実績)
7. 3ステップ(課題を見つける→アイデア→誰の役に立つか)
8. 受講生の声: BEFORE/AFTER+成果3点+本人引用のカード型を約10連発(受賞・採択・メディア・登壇・月商◯倍)
9. アワード実績(経産省JETRO「始動」14名・シリコンバレー派遣2名・RED TOKYOファイナリスト等)
10. メディア掲載120件超のロゴ壁
11. 企業推薦文(類設計室、NTT西日本 QUINTBRIDGE、パソナ — 顔写真+実名+役職)
12. 受講生ストーリー5本(Before/After 物語形式)
13. 共感パート(「私なんかで大丈夫?」→「特別でなくてもいい」)
14. プログラム詳細 Day1〜4(北極星を決める→企画の土台→プレゼン台本→企画の解像度)
15. 過去参加者の声(無料とは思えない等)
16. ミッション・理念
17. 参加までの流れ(メール入力→ボタン→LINEオープンチャット)
18. 最終CTA+フッター(特商法表記・免責事項・プライバシーポリシー)

CTAブロック(メール入力+緑ボタン)は**同一のものを本文中に5回以上反復**。どこで読むのをやめても直近に登録枠がある。

## 3. 上手い点(自社ファネルに移植する価値があるもの)

| 要素 | 実装 | 効果 |
|---|---|---|
| 摩擦最小のオプトイン | 入力はメール1項目。プロフィール等は聞かない | フォームCVR最大化。属性把握は後段(LINE・チャレンジ内)へ先送り |
| 打ち消し表示のスクリーニング転用 | 「3年かかる/短期成果の方は不向き」を目立つ位置に | 法務対応と冷やかし排除を1行で両立。断り文句が誠実さの演出になっている |
| 非金銭実績を主証拠にする | 受賞・採択・メディア件数・登壇が前面。金額は「月商7倍」等の相対値中心 | 景表法リスクと媒体審査落ちリスクが低い。金額実績より反証されにくい |
| 第三者権威の三層積み | ①行政/省庁プログラム採択 ②大手企業の実名推薦文 ③メディアロゴ壁 | 自己申告実績への依存を下げる。B2B文脈で特に効く |
| 成果物の明示 | 「企画書とプレゼン台本が手に入る」 | 無料イベントの参加率(show率)対策。「聞くだけセミナーではない」の差別化 |
| 事例カードのテンプレ化 | 見出し(変化の一文)→帯→顔写真→BEFORE箇条書き→AFTER成果3点→本人引用 | 同一フォーマット量産で制作コスト減+広告素材へ転用可能 |
| 配信チャネルの一本化 | 案内はLINEオープンチャットのみ | ツール併用なし。運営コスト減 |
| LP×広告のバリエーション運用 | パス /lp-ad002/ + utmにMetaのID群 | 広告別にLPをテストし、成約まで追跡する計測設計 |

## 4. プラチナ顧問ファネル(当方設計)との違い

| 観点 | ACTION(SBC) | プラチナ顧問ファネル設計 |
|---|---|---|
| フロント | 無料4日間ライブチャレンジ(コホート) | 録画VSL(エバーグリーン) |
| 主宰者の稼働 | ローンチ毎に4夜ライブ+チャット運営(重い) | 面談と週次判断のみ(軽い) |
| スクリーニング | 文言による自己選別+無料参加のみ(フォーム審査なし) | スコアリング付き審査フォーム+面談前ナーチャリング |
| 教育の深さ | 4日間の共同作業で信頼構築(非常に深い) | VSL60分+事例配信(浅め、その分成約は面談で) |
| ターゲット | 起業前後の個人(想い先行・女性中心) | 既に事業を持つオーナー(B2B) |
| 単価帯(推定) | スクール型・中単価を口数で | 顧問60〜100万の高単価少数 |
| 再現時の注意 | 「片手間」にはならない。ライブ日程が売上の律速 | 商品力と面談力に依存 |

**結論:** ユーザーが以前見たSBC事例カード(梅崎真理子さん等)は、このLPの「受講生の声」セクションの部品。ジャンルと証拠の見せ方は近いが、ファネルの駆動方式は別物 — ACTIONは「ライブで濃く教育して売る」型、プラチナ顧問ファネルのコピーが謳うのは「ライブなし・自動で絞って面談で売る」型。前者は労働集約、後者は仕組み集約。

## 5. 移植の推奨(実務設計書への反映ポイント)

1. **申込フォームStep1をメール(またはLINE)1項目に簡素化**し、スコアリング設問はStep2へ完全分離する(実務設計書§2-2の徹底)。
2. VSL・LPの証拠パートは**非金銭実績(事例数・継続率・登壇・掲載)を主、金額を従**に組み替える。金額は相対値+打ち消し表示。
3. 打ち消し表示を「◯◯な方には不向きです」の形でオファー直前に置き、**法務文言をスクリーニング文言として設計**する。
4. 事例はACTION型カードテンプレ(見出し→BEFORE→AFTER成果3点→本人引用)で量産し、LP・VSL・広告素材で共用する。
5. 年1〜2回だけ、既存リスト向けに**小規模チャレンジ(3〜4日)をスポット開催**する選択肢は残す。エバーグリーンで取り切れない「教育不足層」の刈り取りに使えるが、常設はしない(片手間原則を崩すため)。
