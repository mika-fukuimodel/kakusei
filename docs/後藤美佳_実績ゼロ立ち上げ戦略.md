# 後藤美佳 実績ゼロ立ち上げ戦略 ―― データ無し・制度実績無しで売り始める

作成日: 2026-09-05 JST
前提の変化: REVERAにはまだ参加者データが無い。福井県プロポーザルも消滅。**使えるのは後藤美佳個人の実績・知見・制作物のみ。**
位置づけ: [海外展開設計書](./後藤美佳_海外展開_REVERAメソッド販売設計.md) の§3(説得構造)と§7(ロードマップ)を本書が上書きする。商品ピラミッド・ファネルの最終形(§2, §4)は変更しない ―― **到達の順番だけを変える**。

---

## 0. 結論

**データが無い今、広告ファネルは回さない。回すのは「創業者直販(founder-led sales)」であり、最初の商品は「証拠そのもの を一緒に作る権利」= Founding Practitioner Program。**

- 実績が無いことを隠す・盛るのではなく、**「方法論の創設期に、設計者本人と共同でメソッドを完成させる」というオファーに転換**する。創設期にしか売れない商品であり、データが無いことがむしろ参加理由になる。
- エバーグリーンファネル・広告出稿・正規価格の認定は、**事例カード5枚が揃った時点で解禁**(前設計書§4へ接続)。広告は証拠を増幅する装置であり、証拠の代わりにはならない。
- 言ってよいこと/いけないことの規律を最初に固定する: データが無い間、「効果があります」は言わない。言えるのは**理論(なぜ効くはずか)・設計(どう作ったか)・後藤自身の経験**の3つ。この誠実さ自体を信頼の担保として前面に出す。

## 1. いま手元にある「個人の実績」の3分類

証拠は顧客データだけではない。データ無しでも次の3種は今日から使える。

### (1) 思考の証明(すでにある・最強)
- 七段階覚醒モデルそのもの(名称・順序・思想が体系化済み)
- 4層の科学的説明体系(脳神経/心理/内分泌/発達環境)―― [外部基準依存の理解](./外部基準依存の理解.md) は、そのまま英語ホワイトペーパーと講演の原稿になる完成度がある
- **公開の仕方**: 出し惜しみしない。理論の全公開が「この人は本物だ」の一次証拠になる(ACTION分解で確認した「概念は全部見せる」方式)

### (2) 実行の証明(すでにある・過小評価しがち)
- REVERA01が**動くソフトウェアとして実在する**こと。仮名設計・RLS・役割構造まで作り込んだ事実は、「語るだけのコーチ」との決定的な差。データが無くても「思想をここまで実装した人」は世界的に稀
- **見せ方**: 3分のプロダクトデモ動画。「参加者データはまだありません。だからこそ創設メンバーを募っています」と明言してよい

### (3) 結果の証明(これから作る・本戦略の目的)
- Founding Cohortと国内ミニパイロット(§3)で製造する。目標: **90日で仮名事例カード5枚**

### 要記入: 個人実績の棚卸しテンプレート
以下は後藤本人にしか書けない。埋まった項目だけをプロフィールに使う(**空欄を推測で埋めない・盛らない**)。

| 項目 | 記入欄 |
|---|---|
| 支援・対人援助の従事年数と現場(どこで・誰を・何人) | (要記入) |
| モデル着想の原体験(なぜこの7段階に至ったか) | (要記入) |
| 職歴・資格・学んだ理論的背景 | (要記入) |
| 登壇・執筆・メディア(件数不問、1件でも) | (要記入) |
| これまでに個人として伴走した人の変化の実例(仮名・本人同意) | (要記入) |

このうち**「原体験」が海外向けストーリーの主軸**になる。実績の数が無い局面では、Why(なぜ私がこれを作ったか)が数字の代替をする。

## 2. 最初の商品: Founding Practitioner Program

| 項目 | 設計 |
|---|---|
| 定員 | 8名(少なさが価値。8席と言い切る) |
| 対象 | 支援職・コーチ・HR・NPO運営者(海外+国内混成で可。海外比率を意識的に確保) |
| 価格 | 将来の正規認定($5,000〜8,000)の30〜40% = **$1,800〜2,500**。無料にしない(無料の受講生は事例にならない) |
| 内容 | 12週。週1ライブ(後藤)+ REVERA01支援者アカウント + 各自の現場1ケースへの適用を後藤が直接スーパーバイズ |
| 交換条件(契約に明記) | ①仮名での事例化に同意 ②ステージ遷移の記録をアプリに残す ③修了時の推薦文(顔出しは任意) |
| 特典 | Founding Practitioner の永久称号 / 正規認定への無償アップグレード / メソッド改訂への命名的関与 |

**オファーの一文(英語):**
> The method is complete. The evidence is being written — by the first 8 practitioners. This cohort will never exist again.
> (メソッドは完成している。証拠はこれから最初の8人が書く。この期は二度と存在しない。)

「実績がまだ無い」をこの一文で**希少性の宣言**に変換する。以後のすべての事例カードに「Founding Cohort出身」と刻まれるため、初期参加者の価値も守られる。

## 3. 販売動線(広告ゼロ・後藤の実働で回す)

```
① リスト作り: LinkedInで対象職種を50名リストアップ(支援職・trauma-informed系コーチ・
   日本文化に関心のある実践者)+ 既存人脈・SNSでの告知
② 直接アウトリーチ: テンプレではない個別メッセージ。売り込まず
   「無料のライブ・ステージ診断ワークショップ」へ招待
③ 月1回のライブワークショップ(90分・英語字幕/通訳):
   前半 = 7段階モデルと4層理論のダイジェスト講義
   後半 = 参加者が持ち込んだ実ケースを後藤がその場でステージ診断してみせる
   ← データが無い人間の最強の営業は「目の前で診断してみせる」こと。能力の実演が実績の代替
④ 希望者と個別面談(30分)→ Founding オファー提示
⑤ 8席が埋まったら締切。以後はウェイトリスト
```

- ③はACTION型チャレンジの縮小版(1回完結)。録画は切り出してコンテンツ資産化する。
- 週次の後藤の実働: アウトリーチ2h+ワークショップ準備/実施2h+面談2h = **6h前後**。
- KPIは3つだけ: アウトリーチ返信率 / ワークショップ参加数 / 面談→成約率。

## 4. 国内ミニパイロット(福井プロポの代替)

行政の大型案件は実績ができてから再挑戦する。今は逆に小さく:

- 県ではなく**1つの現場**(福祉事業所・就労支援・NPOのいずれか1団体)と、参加者5〜10名×12週の小規模パイロットを直接契約する(有償が理想、最低でも実費)。
- 目的は収益ではなく **REVERA01に最初のステージ遷移データを発生させること**。これが「Stage 1→3 in 12 weeks (n=8)」という世界どこでも通じる証拠の第1号になる。
- 倫理面: 参加者同意・仮名運用(既存設計のまま)・支援現場の管理者経由での実施。
- 行政再挑戦は、このパイロット報告書(A4数枚で良い)を持ってから。プロポは「実績の出口」であって入口ではない。

## 5. コンテンツエンジン(信頼の複利・週2時間)

個人実績のみで戦う期間は、**本人の思考が公開されている量**がそのまま信用になる。

- 週1本、英語記事(LinkedIn/Medium): 外部基準依存の理解.md を8〜10本に分割翻訳するだけで2ヶ月分ある
- ワークショップ録画の切り出しクリップ(診断の実演場面)
- 月1本、「Building REVERA」ビルドログ(データがまだ無いことも含めて公開で作る = 誠実さの演出と初期ファン化)

## 7. 規律(データ無し期間の禁止事項)

1. 効果・成果の断定表現を使わない(「◯◯が改善します」→「◯◯を狙って設計しています」)。
2. 他人の実績・一般論の数字を自分の実績のように見せない。
3. 無料で際限なく提供しない(無料枠はワークショップ月1回のみ。個別相談は面談枠に一本化)。
4. 8席を埋めるために審査を緩めない。事例化に協力できない人は高くても断る ―― 今期の商品は売上ではなく**証拠**だから。
