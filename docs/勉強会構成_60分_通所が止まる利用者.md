# 60分勉強会 構成案 ――「通所が止まる利用者への関わり方」

作成日: 2026-09-09 JST
用途: 事業所向け無料勉強会(所内開催 or 複数事業所合同・オンライン可)。パイロット受注の営業装置であり、営業と呼ばせない中身にする。
関連: [営業資料 90日パイロット](./営業資料_事業所向け90日パイロット.md) / [外部基準依存の理解](./外部基準依存の理解.md)

対象者: 施設長・サービス管理責任者・支援員(**決裁者=施設長の同席を開催条件にする**。支援員だけの会は開かない)
タイトル案: 「『意欲がない』で止まらないケースの見立て方 ― 通所が止まる利用者への関わり」

---

## 全体設計の原則

1. **60分のうち50分は本当に役に立つ研修にする。** 売り込みは最後の10分だけ。中身が濃いほどパイロットは売れる(ACTION分解で確認済みの構造)。
2. 山場は「参加者の実ケースをその場で見立てる」ライブデモ。ここで施設長が「うちの支援員に持たせたい」と思えば終わり。
3. 語彙は現場の言葉のみ: 通所・定着・声かけ・見立て・減収。理論語は「学習性無力感」まで(これは福祉現場に通じる)。

---

## 進行台本(分単位)

### 0:00–0:05 導入 ― 問いから入る(5分)
- 「最初に1つだけ伺います。**この3ヶ月で、通所が止まった・不安定になった利用者は何名いますか。**」(挙手や口頭で数名に聞く)
- 「その方々に共通するのは『意欲の問題』に見えること。今日はそれが**意欲の問題ではない**こと、そして関わり方をどう変えるかを、50分で持ち帰っていただきます」
- 自己紹介は3行で切り上げる(経歴を語る時間ではなく、後半の見立てで証明する)。

### 0:05–0:20 第1部 ― 「動かない」の正体(15分)
- 現場あるあるの提示: 「お金がないから弁当が作れない」「時給がわからないと仕事をやらない」型の発言(外部基準依存の理解.md §1の具体例をそのまま使う)。
- 種明かし: これは怠慢ではなく、**「自分で基準を作って動く」機能が、環境適応の結果オフになっている状態**。
  - 学習性無力感(何を選んでも結果が変わらなかった経験の蓄積)
  - 「損しないか」の確認が取れるまで行動がフリーズする脳の防御反応
  - 責任を外部条件に預けるのは、本人にとって合理的な自己防衛
- **ここで必ず言う一文**: 「だから、励ましと目標設定は効きません。**効かないどころか、『また自分で決めさせられる』という脅威になって、逆効果になります**」
- 支援員の頷きが取れるパート。resonanceの山その1。

### 0:20–0:35 第2部 ― 段階で見立てる(15分)
- 「動かない」は一枚岩ではなく段階がある、として見立ての枠組みを提示(7段階の対外簡略版。名称はそのまま出さず「閉じている段階/信頼をつくる段階/本人の言葉が出てくる段階/自分で決め始める段階…」のように機能で説明)。
- 各段階につき「効く関わり/逆効果の関わり」を1つずつ、対比表で見せる。
  - 例: 信頼をつくる段階に「目標シートを書かせる」→逆効果 / 「選ばなくていい小さな選択肢を差し出す」→効く
- 配布物: **段階×関わり方の早見表A4×1枚**(この勉強会最大の持ち帰り価値。裏に事業所の連絡先とパイロット概要を刷っておく)

### 0:35–0:50 第3部 ― ライブ見立て(15分・山場)
- 「では実際にやってみます。**いちばん手応えのないケースを1件、仮名で教えてください**」(事前に施設長へ1件用意を依頼しておく。挙手が出なければそのケースで)
- 聞く→段階に置く→「いま現場でやっている関わりのうち、◯◯は段階に合っていない。明日からは◯◯に変える」まで**言い切る**。
- 2件目まで扱えれば理想。時間が余れば質疑をここに吸収。
- この15分が営業のすべて。第2部までは知識、ここで「この人は現場がわかる」に変わる。

### 0:50–1:00 クロージング(10分)
1. まとめ1分: 「意欲の問題ではなく段階の問題。段階が変われば関わりが変わり、通所が変わります」
2. 金額の接続2分: 「通所が止まると、御所の規模なら月おおよそ◯円の減収です(概算)。これは支援の質の話であると同時に、経営の話です」
3. パイロット案内5分: 営業資料を配布し、90日パイロットの内容・費用・**成果保証(改善しなければ次の90日無償)**・「効果実証の第一号である」ことを正直に説明。
4. 次の一歩2分: 「興味のある事業所さまとは、個別に30分、貴所の利用実績データで減収額を試算する場を設けます」―― **その場で候補日を2つ提示して仮押さえする**(後日連絡にしない)。

## 開催の実務

- 形式: 所内開催(1事業所)を基本。合同開催は3事業所まで(多いと個別ケースを扱えない)。オンライン可だがライブ見立ての熱量は対面が上。
- 事前準備: 施設長に①参加者の職種と人数 ②「手応えのないケース」1件の用意 ③直近3ヶ月の通所実績の概観、を依頼(③は出なくても開催する)。
- 持ち物: 早見表A4(人数分)/ 営業資料(決裁者分のみ)/ 試算用の単価メモ。
- 禁止事項: その場での値引き / 効果の断定 / 理論パートの延長(15分を超えない)/ 医療的判断への言及。
- 終了後24時間以内: 施設長へ御礼+当日扱ったケースの見立てメモ(A4半分)+試算面談の候補日を送る。**メモの質が受注率を決める。**

## KPI(勉強会1回あたり)

| 指標 | 目安 |
|---|---|
| 決裁者の出席 | 100%(出席がなければ開催しない) |
| ライブ見立ての実施 | 1件以上(0件の会は構成失敗) |
| 試算面談の仮押さえ | 開催事業所の50%以上 |
| 試算面談→パイロット成約 | 30〜50% |
