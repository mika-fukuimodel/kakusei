# 外部基準依存の理解 ―― 支援者向け解説

> 「自分で選択する基準を作らず、選択の基準を外部に求める」参加者を理解するための資料。
> 覚醒モデルの **ステージ三(潜在意識の顕在化)→ ステージ四(主体の回復)** の移行地点でつまずく人を対象とする。

**関連:** [覚醒モデル(アプリ本体)](../index.html) ／ 公開サイト: <https://mika-fukuimodel.github.io/kakusei/>

---

## 0. この資料の目的

支援の現場で、次のような言葉に出会うことがある。

- 「お金がないと弁当ができない」
- 「時給がわからないと仕事をやらない」

一見すると、怠慢・意欲不足・言い訳に見える。しかしこれらは、
**「外部に基準を預けたほうが安全だった環境」を生き延びた結果できあがった、脳と心の適応パターン**である。

支援者が「なんで自分で決められないの?」と苛立つと、関係が壊れる。
まずこの現象を「性格の問題」ではなく「適応の結果」として理解することが、支援の出発点になる。

---

## 1. 違和感の正体

| | 基準を **内側** に持つ人 | 基準を **外部** に求める人 |
|---|---|---|
| 判断の起点 | 自分の目的から逆算する | 外部条件が確定するまで起動しない |
| 弁当の例 | 「工夫すれば作れる」と自分で解決 | 「お金がない → 無理」で思考停止 |
| 仕事の例 | 意味・目的から着手を判断 | 「時給が不明 → 損の可能性 → やらない」 |

後者は **「決められない」のではなく、「自分で基準を作る」という選択肢が学習の中で消去されている**状態である。

---

## 2. 四つの層からの説明

### ① 脳神経科学の層

- **前頭前皮質(vmPFC / OFC)の価値づけ機能の低下**
  自分で基準を作るとは、脳内で「AとBのどちらが自分にとって価値が高いか」を内的に計算する作業。
  慢性ストレス・貧困・否定的養育下ではこの領域の発達が抑制され、内的なものさしが育たない。
  代わりに「お金」「時給」という **すでに確定した外部の数値** に依存する(自分で計算しなくてよいため)。

- **扁桃体優位・安全確認モードのデフォルト化**
  不安定な環境で育つと扁桃体(脅威検知)が過敏になり、行動前に「損しないか/怒られないか」の確認が必須になる。
  「時給がわからない=損の可能性=脅威」→ 確定情報が来るまで行動をフリーズさせる。
  → 決められないのではなく、**扁桃体が GO サインを出していない**。

- **ドーパミン報酬予測系のチューニング**
  ドーパミンは「予測できる報酬」に強く反応する。
  「時給1200円」という明示報酬には点火するが、「やってみたら得られるかも」という内発的・不確実な報酬には反応が弱い。
  努力が報われた経験が乏しいと、この回路が **外部の確定報酬にしか点火しない** よう最適化される。

### ② 心理学の層

- **外的統制型(External Locus of Control)**
  結果は運・他者・環境で決まると感じるため、基準を外に置くのが本人にとって合理的になる。
  「お金がないと弁当ができない」は、弁当を作れるかを "お金" という外部要因に帰属している典型。

- **学習性無力感(セリグマン)**
  「何を選んでも結果は変わらなかった」経験の蓄積により、選ぶこと自体をやめる。
  基準がなくて動けないのではなく、**「自分で基準を作る」という選択肢が消去されている**。

- **自己効力感(バンデューラ)の欠如**
  「自分は状況をコントロールできる」感覚が低いと、自分で判断する心理的コスト(失敗の全責任)が耐えられない。
  外部基準は **責任の外部化** でもある。「時給が安かったからやらなかった」なら責任を条件に転嫁できる ―― 自己防衛として非常に効率的。

- **決定疲労・認知的節約**
  慢性ストレス(特に貧困)下では認知資源が枯渇しており、「外部の数字に従う」省エネ戦略が発動する。

### ③ ホルモン・内分泌の層

- **コルチゾール(慢性ストレス)**
  長期の高コルチゾールは前頭前野を萎縮させ扁桃体を肥大させる。
  長期目標からの逆算(=自分の基準)が弱まり、目先の脅威回避が優先される。
  貧困は慢性コルチゾール過剰の温床 ―― **「お金がない」という状況自体が判断力を生理的に削る**(貧困の悪循環の神経内分泌的な根)。

- **ドーパミン** ―― 確定した外部報酬に依存するチューニング(①参照)。

- **セロトニン** ―― 低いと不確実性への耐性が下がり、確定情報(外部基準)を渇望する。

- **オキシトシン(愛着)** ―― 不足すると自分の内側に "よりどころ" を持てず、外側の基準にしがみつく土台になる。

### ④ 家庭環境・発達の層(最も上流の原因)

- **(a) 条件付きの愛・評価**
  「役に立つ子なら価値がある」で育つと、価値判断の基準が常に外(親の評価)にあった。
  「時給がわかれば動く」= 外部が価値を確定してくれれば動ける、という幼少期構造の再演。

- **(b) 過干渉・先回り(選択の剥奪)**
  親が全部決める養育では「自分で選び、結果を引き受ける」練習がゼロ。主体的選択の回路が育たない。

- **(c) 否定・支配・予測不能な環境**
  自分の判断が常に否定・上書きされ、「自分で決めても意味がない」を学習(→ 学習性無力感)。
  予測不能さは扁桃体を過敏化させる(→ ①)。

- **(d) 貧困・欠乏(スカーシティ)の文化**
  「お金がないと〇〇できない」が家庭の世界観として刷り込まれると、金銭が行動可能性の判断基準の座を占める。
  「工夫すれば安く作れる」という内的解決より先に「金がない→無理」で思考が停止する(欠乏による認知帯域の占拠)。

## 3. 二つの具体例への当てはめ

| 表面の言葉 | 内側で起きていること |
|---|---|
| **お金がないと弁当ができない** | vmPFC の内的価値計算より、欠乏スキーマ(家庭刷り込み)+ コルチゾールによる目先思考が優先。「工夫」という自己効力感の発動が学習上消えている |
| **時給がわからないと仕事をやらない** | ドーパミンが確定外部報酬にしか点火せず、扁桃体が "損の可能性" を脅威判定。責任の外部化(自己防衛)も兼ねている |

**共通構造:**
> 「自分の目的(何のために・どうありたいか)を起点に逆算する内的基準」が育っておらず、
> 代わりに "確定した外部条件" が来るまで行動を保留する、省エネ & 自己防衛モードが常時起動している。

## 4. 覚醒モデルとの接続 ―― 支援上の含意

この状態の参加者は、多くの場合 **ステージ三(潜在意識の顕在化)→ ステージ四(主体の回復)** の移行地点で止まっている。

1. **「なぜ自分で決められないの?」は禁句**
   外的統制と学習性無力感を強化するだけになる。

2. **超・小さな選択から成功体験を積ませる(ステージ五「小さな挑戦」の前倒し)**
   「どっちがいい?」レベルで、選んで・結果を引き受けて・肯定される回路を再建する。

3. **確定情報を "一度は与えつつ"、徐々に不確実性への耐性を上げる**
   いきなり「自分で決めろ」は扁桃体をフリーズさせる。段階的に曖昧さを増やす。

4. **安全基地(信頼=ステージ二)が前提**
   支援者が一時的に外部から "よりどころ" を提供し、それを本人の内側に内在化させていく。
   これが「主体の回復」の神経的な実態(オキシトシン的な安全基地の内在化)である。

## 5. 支援者チェックリスト

- [ ] 参加者の「〜がないとできない」を、言い訳ではなく **適応パターン** として受け取れているか
- [ ] 「なぜ決められないの?」という詰問をしていないか
- [ ] 判断を迫る前に、**信頼(安全基地)** が十分に構築されているか
- [ ] 本人が **自分で選べる粒度** まで選択肢を小さくしているか
- [ ] 選んだ結果に対して **肯定・承認** を返せているか
- [ ] 外部の確定情報を段階的に減らし、不確実性への耐性を育てているか
