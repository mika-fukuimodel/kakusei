# プラチナ顧問ファネル 実務設計書

作成日: 2026-08-02 JST
目的: セールスコピーで謳われている以下の3要素を、実際に運用可能なレベルまで分解し、「働き方の仕組み」「手段」「タスク」「期間」を定義する。

> ①戦略的な顧問ファネル設計
> ②スクリーニングしてもCVRが落ちない
> ③戦略的出稿

対象読者: サロン経営と並行してコンサル・顧問業を高単価で販売したいオーナー、およびその実務を支援するチーム。

**前提の整理(プロの視点):** 元コピーの「SNS無し・セールスレター不要・ライブ無し・冷やかし面談ゼロ」という打ち消しの羅列は、裏返すと **「広告→録画VSL→審査制申込→適格者のみ面談→高単価成約、不成約者には継続商品」** という1本のエバーグリーン(常時稼働)ファネルを指している。本書はその1本を精度高く作り、サロン業の片手間(オーナー実働 週8〜10時間)で回すための設計である。売上金額の再現は市場・商品力・広告予算に依存するため保証できないが、構造そのものは業界標準の高単価B2Bファネルであり、以下の通り完全に実装可能である。

---

## 0. 全体像(ファネルマップ)

```
広告(Meta / YouTube / Google)
   │  ← ③戦略的出稿
   ▼
LP(登録ページ: 動画視聴の予約 or 即時視聴)
   │
   ▼
VSL(録画セミナー 30〜60分) ← セールスレター・ライブ不要の正体
   │
   ▼
審査制申込フォーム(スコアリング付き) ← ②スクリーニング
   │
   ├─ 適格 ──► 面談前ナーチャリング ──► 個別面談(オーナー実施)──► 本命商品成約(60〜100万円)
   │                                           │
   │                                           └─ 不成約 ──┐
   └─ 不適格 ─────────────────────────────────────────────┴──► 継続商品(月額 or 教材, 1〜5万円/月)
                                                                  ← 「申し込みに至らなかった見込み客にも売れる」の正体
```

サロン集客も同じ骨格(広告→LP→予約→来店→高単価コース)で作るため、**管理は1つの仕組み・1つのダッシュボード**に統合できる。「サロンとコンサルを別軸で管理する必要なし」とはこの意味である。

## 1. ①戦略的な顧問ファネル設計

### 1-1. 商品設計(ファネルより先に決める)

ファネルは商品の器にすぎない。順序は必ず「商品→メッセージ→ファネル→広告」。

| 階層 | 商品 | 価格帯 | 役割 |
|---|---|---|---|
| 本命(バックエンド) | 顧問契約 / 6ヶ月コンサル | 60〜100万円(一括 or 分割) | 利益の柱。月8桁はここで作る |
| 面談 | 個別戦略面談 | 無料 or 5,000〜11,000円 | 販売の場。有料化は冷やかし排除にも効く |
| 継続(ダウンセル) | 会員制コミュニティ / 月額講座 | 月1〜5万円 | 不成約者・不適格者の受け皿。LTVの底上げ |
| 教材(任意) | 買い切り講座 | 3〜10万円 | 継続への入口。自動販売可 |

**本命商品の設計要件:**
- 成果物ベースで定義する(例:「90日で高単価メニューの販売導線を一緒に構築し、初回販売まで伴走」)。時間売り(月◯回相談)ではなく成果売りにすることで単価が上がる。
- 提供形態は「月2回のZoom + チャットサポート + テンプレート一式」など、オーナーの実働が週数時間で収まる形に固定する。
- 定員を設ける(例: 月5名まで)。これは後述のスクリーニングの正当性の土台になる。

### 1-2. VSL(ビデオセールスレター)の構成

「セールスレター不要」「ライブ不要」の正体は、**一度作って回し続ける録画動画**である。

| パート | 時間目安 | 内容 |
|---|---|---|
| フック | 0〜3分 | 誰向けか・何が得られるか・実績の提示 |
| 問題の再定義 | 3〜15分 | 「SNS頑張る・多店舗展開」が構造的に儲からない理由を論証 |
| 解決の仕組み | 15〜35分 | 高単価顧問モデルの3ステップ(概念は全部見せる。実装手順は面談・本命で提供) |
| 証拠 | 35〜45分 | 事例・数字(※根拠資料を保持すること。後述の法務参照) |
| オファー | 45〜60分 | 面談の案内 +「審査制・定員制」の明示 → 申込フォームへ |

制作は台本執筆(オーナー)→撮影(スマホ+ピンマイクで可)→編集(外注)。台本が9割。

### 1-3. LP・フォーム・面談の設計

- **LP:** ヘッドライン + VSL埋め込み + 申込ボタンのみの1カラム。長文レター不要(VSLが代替)。制作はテンプレートベースのLPツールで1〜2日。
- **申込フォーム:** §2で詳述。スコアリング項目を仕込む。
- **面談(60〜90分):** 型を固定する。①現状ヒアリング(15分)→②理想と障害の言語化(15分)→③診断: ギャップの構造化(15分)→④解決策として本命商品の提示(15分)→⑤条件確認とクロージング(15分)。台本化してオーナー以外(将来のセールス担当)でも回せる状態にしておく。
- **不成約時:** その場で継続商品を案内(「まず月額で仕組みだけ学ぶ」導線)。面談後の自動メール/LINEでも7日間フォロー。

### 1-4. KPIモデル(設計段階で数値の骨格を持つ)

月商8桁の逆算例(本命80万円の場合):

| 指標 | 目標値の目安 | 月間数値例 |
|---|---|---|
| 広告費 | — | 100〜150万円 |
| LP登録単価(CPL) | 3,000〜8,000円 | 登録 200件 |
| VSL視聴→申込率 | 8〜15% | 申込 20件 |
| 審査通過率 | 50〜70% | 面談予約 12件 |
| 面談実施率(show率) | 70〜85% | 実施 9件 |
| 面談→成約率 | 30〜50% | 成約 3〜4件 |
| 本命売上 | — | 240〜320万円 |
| 継続商品(不成約16件×20%×月3万) | — | 月10万円ずつ積み上げ |

初月からコピーの数字(1,800万超)を狙うのではなく、まずこの基礎モデルを黒字で回し、§3のスケール手順で予算を段階的に引き上げる。8桁は「単価100万×月10件成約+継続のストック」が成立した時点の姿である。

## 2. ②スクリーニングしてもCVRが落ちない仕組み

### 2-1. なぜ普通はスクリーニングするとCVRが落ちるのか

- 入力項目が増えるほどフォーム離脱が増える(摩擦)。
- 「審査」という言葉が拒絶の予感を与える(心理的コスト)。
- 落とした人を捨てるので、母数減がそのまま売上減になる。

### 2-2. 落ちなくする4つの設計

**(1) 審査を「価値」として演出する(ポジショニング反転)**
- 「定員制のため、全員はお受けできません」「現状を伺い、成果が出る方だけご案内します」と明示。審査は障壁ではなく**商品の希少性・誠実さの証明**として提示する。VSL内で必ず予告し、フォームで初見にならないようにする。
- 効果: 申込の質が上がるだけでなく、「選ばれたい」動機で申込率自体が上がる(高単価商材では定番の挙動)。

**(2) フォームの摩擦設計(2ステップ化)**
- Step1: 名前・LINE/メールのみ(ここでリード確保。以降は落ちても追客可能)。
- Step2: スクリーニング設問。設問は5〜7問に絞り、全て選択式にする。
  - 例: 現在の月商レンジ / 事業歴 / 投資可能予算レンジ / 着手時期(今すぐ〜情報収集) / 意思決定者本人か
- 各選択肢に点数を割り当て、合計点で「適格(面談へ)/準適格(教材・継続へ)/不適格(メルマガのみ)」を自動振り分け。判定はスプレッドシート+フォームツールの条件分岐で足りる。ツールを増やさない。

**(3) 落ちた人を捨てない(不適格=別商品の顧客)**
- 不適格・準適格には自動で継続商品/教材のオファーを出す。これが「申込に至らなかった見込み客にも継続商品が売れ、広告費ゼロで積み上がる」の実体。スクリーニングは母数を捨てる行為ではなく、**母数を価格帯別に仕分ける行為**に変わるため、ファネル全体のCVR(=収益化率)は落ちない。

**(4) 面談前ナーチャリングでshow率と成約率を守る**
- 予約直後: 確認メッセージ + 事前課題(現状シート記入10分)。課題提出者はshow率・成約率が大きく上がる。
- 前日・当日: 自動リマインド(LINE/メール)。
- 予約〜面談の間: 事例動画2〜3本を自動配信(教育の続き)。
- これにより「審査で絞る→少数精鋭→1件あたりの成約率が上がる」が成立し、**面談数を減らしてもCVR×単価で売上が維持される**。「冷やかしとの無駄な面談ゼロ」はこの合成結果である。

### 2-3. 運用ルール

- スコアリング閾値は固定せず、毎週の面談所感(冷やかし混入率・機会損失)を見て月1回だけ調整する。頻繁にいじらない。
- 面談枠はオーナーのカレンダーで週6〜10枠に制限し、予約ツールで自動管理。枠の希少性がそのまま演出になる。

## 3. ③戦略的出稿

「SNS更新なし」の正体は、**オーガニック投稿を捨てて有料広告に一本化する**こと。作業が「毎日投稿」から「週1回の数値判断」に変わるため、片手間運用が成立する。

### 3-1. 媒体戦略

| 媒体 | 役割 | 備考 |
|---|---|---|
| Meta広告(Instagram/Facebook) | 主力。サロンオーナー等の事業者層に類似・興味関心で到達 | B2B風クリエイティブでToC(一般客)を自然に除外 |
| YouTube広告 | VSLと相性が良い。教育型の長尺インストリーム | 第2の柱。Meta検証後に追加 |
| Google検索 | 「サロン コンサル」等の顕在層を刈り取り | 少額で常時稼働 |

**ToC混入の排除(「ToC向け特典なし」の実装):** クリエイティブの1行目で「サロン経営者の方へ」と名指しする/オファーを事業者にしか意味のないもの(利益・採用・単価)にする/フォームStep2で事業者以外を自動で継続商品側へ流す。ターゲティング設定より**クリエイティブと導線で絞る**方が確実で、媒体アルゴリズムとも喧嘩しない。

### 3-2. クリエイティブ生産システム

- 型は3種のみ: ①実績提示型(数字+一言) ②問題共感型(「毎日投稿してるのに…」) ③反常識型(「多店舗展開はやめなさい」)。
- 週次で「静止画3本 or 動画1本」を新規投入。素材はVSL撮影時にまとめ撮りした切り出しを使い回す(追加撮影ほぼ不要)。
- 制作はオーナーが一言コピーを出し、デザイン/編集は外注。オーナー実働は週30分。

### 3-3. テストとスケールのルール(判断を仕組み化)

| フェーズ | 日予算 | ルール |
|---|---|---|
| テスト | 5,000〜10,000円/日 | 1広告セット×3クリエイティブ。CPL目標の2倍を超えたら3日で停止 |
| 検証 | 10,000〜30,000円/日 | 勝ちクリエイティブに集約。面談予約単価(CPA)と成約まで追う |
| スケール | 勝ち構成の予算を**週20〜30%ずつ**増額 | 一気に倍増しない(学習リセット防止)。増額はROAS(本命+継続のLTV込み)が2.5以上を維持している間のみ |

**管理KPI(週次で見るのはこれだけ):** CPM / CTR / CPL / 申込単価 / 面談予約単価 / show率 / 成約率 / ROAS。スプレッドシート1枚のダッシュボードに毎週金曜に転記(運用代行が記入、オーナーは15分で判断)。

**「動画の視聴率を上げる小手先の改善なし」の実務的意味:** 改善レバーを「広告クリエイティブの差し替え」と「オファー(定員・特典・価格)の変更」の2つに限定し、VSL本編は四半期に1回しか触らない。改善対象を絞ることが片手間運用の生命線。

## 4. 働き方の仕組み(オペレーティングモデル)

### 4-1. 体制と分担

| 役割 | 担当 | 週あたり実働 |
|---|---|---|
| 商品提供(顧問セッション)・個別面談・最終判断 | オーナー本人 | 6〜8時間 |
| 広告運用(入稿・数値転記・週次レポート) | 外注(運用代行 or 業務委託) | — |
| 動画編集・バナー制作 | 外注 | — |
| 事務局(予約管理・リマインド確認・顧客対応一次) | サロンスタッフ兼任 or オンライン秘書 | 2〜3時間 |

サロン現場はスタッフに委譲を進め、オーナーの現場施術は指名客のみ等に段階縮小する。オーナーの時間は「面談」「顧問セッション」「週次の数値判断」の3つに集約する。

### 4-2. 週次リズム(固定カレンダー)

| 曜日 | オーナーのタスク | 時間 |
|---|---|---|
| 月・水 | 個別面談(各日2〜3枠) | 各2h |
| 火・木 | 顧問クライアントのセッション | 各1.5h |
| 金 | 週次数値レビュー(ダッシュボード確認→広告の続行/停止/増額を指示)+ 翌週広告コピー1本出し | 1h |
| 土日 | 原則オフ(サロン現場に立つ場合はここ) | — |

### 4-3. ツールスタック(最小構成・併用しない)

- LP+フォーム+決済: LPツール1つ(例: ペライチ/Utage/ClickFunnels系のいずれか1つ)
- 配信+リマインド: LINE公式アカウント(拡張ツールは1つまで)+ メール
- 予約: 日程調整ツール(TimeRex/Calendly等)
- 面談: Zoom
- 管理: スプレッドシート1枚(リスト・スコア・KPI・入金を全て集約)
- 広告: Meta広告マネージャ(+後にGoogle)

「いろんなツールの併用なし」= 各機能につき1ツール、合計6つ以内に固定し、年1回しか見直さない。

| タスク | 判断基準 | 期間 |
|---|---|---|
| 少額出稿開始(日5,000〜10,000円、クリエイティブ3本) | CPLが目標2倍超で停止・差し替え | 7日サイクル×2 |
| 初回面談の実施と台本改善 | 成約率とヒアリング所感 | 随時 |

**Phase 3の合格ライン(Day 60時点):** 面談→成約率30%以上、広告費込みで黒字、show率70%以上。未達の場合はスケールせず、ボトルネック1点のみ改善して再テスト。

### Phase 4: スケール(Day 61〜90〜)

| タスク | 期間 |
|---|---|
| 週20〜30%ずつ予算増額(ROAS維持を条件) | 継続 |
| YouTube広告・Google検索の追加 | Day 75〜 |
| 面談枠の拡張 or 単価アップ(80→100万円)の判断 | Day 90 |
| サロン集客ファネルを同じ骨格で複製(LPと商品だけ差し替え) | Day 90〜 |
| 四半期レビュー: VSL改訂・商品改定・年間計画 | 四半期ごと |

## 6. 改善ループ(運用開始後の唯一のルーチン)

1. 毎週金曜: ダッシュボード確認(15分)。
2. 異常値が出た指標を**1つだけ**特定する(CPL悪化→クリエイティブ、申込率悪化→VSLオファー部、show率悪化→ナーチャリング、成約率悪化→面談台本 or スコア閾値)。
3. 翌週にその1点だけ変更し、他は固定する。
4. 月1回: スコアリング閾値と価格・定員の見直し。
5. 四半期: VSL本編の改訂。

複数箇所を同時に触らないこと。原因の切り分けができなくなり、片手間運用が崩壊する最大要因になる。

## 7. リスクと法務(必ず実装すること)

- **景品表示法・特定商取引法:** 「売上◯◯万円」「利益◯◯万円」等の実績表示は、根拠資料(売上帳票・広告費明細)を保持し、「成果には個人差があります」等の打ち消し表示を近接配置する。誇大な断定(「必ず」「誰でも」)は使わない。2024年以降、情報商材系の表示規制・執行は強化されている。
- **特商法表記:** 事業者名・所在地・返金条件・支払方法を明記(本リポジトリの privacy/security ページと同様に静的ページで用意)。
- **契約書:** 顧問契約は成果の定義・提供範囲・中途解約条件を書面化。高額分割の場合は決済会社の規約(役務提供期間)に注意。
- **広告アカウント停止リスク:** 誇大表現はMeta審査落ち・アカウント停止の主因。クリエイティブの数字表現は法務チェックと同基準で運用する。
- **属人性リスク:** オーナーが面談と提供を握るため、体調・繁忙で止まる。面談台本と顧問カリキュラムを文書化し、将来のセールス担当・サブ講師に移譲できる状態を Phase 4 で作る。
